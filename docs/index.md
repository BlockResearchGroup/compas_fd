# Constrained form finding with force density

COMPAS FD solves for the equilibrium shape of a network of axial elements with
prescribed force densities. Use the direct solver for fixed supports, or use
the iterative solver to update supports that can slide along geometry.

Start with [installation](installation.md) and the [worked example](examples.md),
then consult the [solver and load guide](tutorial.md) for input conventions.
